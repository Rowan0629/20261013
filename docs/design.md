## 2. 風格

**手機優先、淺色、簡潔。** 暖白色底,單一藍色當主色。自己的訊息是藍色泡泡靠右,別人的是白色泡泡靠左。沒有漸層、沒有裝飾性圖案,重點放在文字好讀、按鈕好按。

> 風格是我在你沒指定時的預設。要改成深色或其他風格,改的是第 3 節的色彩,版面不用動。

### 2.1 目前沒有做的

- **深色模式**:只做了淺色。
- **動畫**:設計稿是靜態的。轉圈圈、提示淡入淡出、按鈕按下的回饋,需要在實作時補上。
- **互動**:按鈕沒有實際行為。

### 3.3 尺寸與圓角

- **所有可點的東西至少 44×44px**(手機)。電腦版的滑過按鈕為 36px。
- 輸入框、按鈕:圓角 12px(輸入代號畫面)或完全圓(膠囊,聊天室)。
- 訊息泡泡:圓角 16px,**靠近發送者的那一角為 4px**。別人的左上角 4px,自己的右上角 4px。
- 泡泡最大寬度:手機 82%(圖片 88%),電腦 60%。
- 手機版面間距:左右 12px;訊息之間 10px;電腦版左右 24px、訊息之間 12px。
- 上方列高 60px(手機)、64px(電腦)。

### 3.4 圖示

全部用線條風格圖示(線寬 2、圓角端點),**不用 emoji 當圖示**。需要的圖示:

人群(在線)、向下與向上箭頭(展開、新訊息)、鉛筆(編輯、更換代號)、垃圾桶(刪除)、圖片、送出(紙飛機)、叉叉(關閉、移除)、下載、斷線(Wi-Fi 加斜線)、警告(圓圈驚嘆號)、轉圈(載入)、對話框(空狀態、標誌)。

## 4. 畫面規格

### 4.1 畫面 A:輸入代號

整頁置中,由上而下:

1. 標誌:56px 的藍色圓角方塊,內有對話框圖示
2. 標題「匿名聊天室」
3. 說明:「不用註冊、不用登入,取一個代號就能進來和大家聊天。」
4. 標籤「你的代號」
5. 輸入框:高 52px,右側顯示「2 / 12」字數。有錯誤時,框線變紅(2px)
6. 錯誤提示(輸入框下方,紅字加警告圖示):「這個代號有人在用,請換一個」
7. 規則提示:「1–12 個字,只能用中文、英文、數字」
8. 主按鈕「進入聊天室」:高 52px,滿寬,藍底白字
9. 底部說明:「瀏覽器會記住你的代號,下次打開就直接進入。第一次進入時會詢問是否允許通知,讓你在別的分頁時也不錯過新訊息。」

> 設計稿只畫了「代號被占用」的狀態。**格式不合**(空白、太長、有符號)用同一個錯誤位置顯示對應文字;**進入中**要讓按鈕顯示「進入中…」並停用,避免連點。

### 4.2 畫面 B:聊天室(手機)

由上而下分四層:**上方列、(連線橫幅)、訊息列表、輸入區**。

#### 上方列

- 左:「匿名聊天室」+ 小字「你是 小明」
- 右:
  - 膠囊按鈕「● 12 人在線 ▾」(高 44px,綠點)。展開時框線變藍、底變淡藍,箭頭向上
  - 44×44 的鉛筆圖示按鈕,無障礙名稱為「更換代號」

#### 進出提示

浮在上方列下方、水平置中,深色膠囊:「● 小花 進入了聊天室」。幾秒後消失,不佔版面。

#### 連線橫幅

位於上方列正下方,滿寬,淡黃底:「斷線圖示 連線中斷,重新連線中…」。恢復後整條消失,下方內容往上補。

#### 手機版線上名單(展開)

- 從上方列下方展開的白色卡片,左右各留 12px,陰影,圓角 16px
- 其餘畫面蓋上半透明遮罩,點遮罩或再點一次按鈕收起
- 標題列:「線上 12 人」+ 靠右「再點一下收起」
- 每一行高 44px:綠點 + 代號。**自己那一行**淡藍底、粗體、右側「(你)」
- 名單過長時卡片內可捲動,底下提示「往下滑可看到其餘 N 人」

#### 訊息列表

- 內容貼底(訊息少時從底部往上堆)
- **日期分隔線**:兩側細線夾著日期字,「今天」「昨天」「10/12」
- **別人的訊息**:靠左。泡泡上方顯示代號;泡泡右側底部是時間
- **自己的訊息**:靠右、藍底白字。時間在泡泡左側;**不顯示自己的代號**
- **已編輯**:泡泡內文字後面接小字「(已編輯)」
- **已刪除**:不填色、虛線框、斜體灰字「此訊息已刪除」;自己與別人的都一樣,只是靠左或靠右
- **圖片訊息**:白色泡泡內嵌圖片(約 220×150),整張是一個按鈕,點了開啟畫面 C
- **自己訊息的操作**:點選自己的訊息後,泡泡下方出現兩顆膠囊按鈕「編輯」「刪除」(各高 44px,刪除為紅字)
- **編輯模式**:該則訊息變成藍色粗框的卡片(寬約 86%),內有「編輯訊息」標籤、文字框、剩餘字數、「取消」「儲存」兩顆按鈕
- **往上滑載入**:列表頂端顯示轉圈圈與「載入更早的訊息…」;載到最早時顯示「已經是最早的訊息」
- **「有 N 則新訊息」按鈕**:浮在列表底部中央的藍色膠囊,附向下箭頭,只在使用者不在底部時出現
- **空狀態**:列表置中,淡藍圓形對話框圖示 + 「還沒有人說話,你先開始吧」+ 說明「你說的話,所有進來這間聊天室的人都看得到。」

#### 輸入區

預設狀態一排三個元件:**加入圖片按鈕**(44px 圓形)、**文字框**(膠囊,預設一行)、**送出按鈕**(44px 圓形,藍底)。沒有內容時送出按鈕為淡藍停用色。

在此基礎上,依狀態往上疊:

| 狀態 | 畫面 |
|---|---|
| 已選圖片 | 輸入列上方多一張預覽卡:56px 縮圖、檔名、大小(例如「2.1 MB」)、44px 的移除按鈕 |
| 接近字數上限 | 輸入列上方右側,紅字「還剩 18 字」 |
| 被頻率限制 | 輸入列上方左側,紅字加警告圖示「送太快了,請稍等一下再送」;文字框內容保留 |
| 文字太長 | 文字框變高(約兩行)以顯示更多內容 |
| 斷線 | 輸入列上方顯示「連線恢復後才能送出」;三個元件全部變灰停用 |

沒有 emoji 按鈕,使用者用手機或電腦內建的 emoji 輸入。

#### 刪除確認

滿版半透明遮罩,中央一張白色卡片:

- 標題「確定要刪除這則訊息?」
- 被刪的內容預覽(灰底小框)
- 說明「刪除後,所有人都會看到『此訊息已刪除』,內容無法救回。」
- 兩顆按鈕並排:「取消」(白底框線)、「刪除」(紅底白字),各高 48px
- 被刪的那則訊息在背景用紅色外框標出

### 4.3 畫面 C:圖片檢視

- 整頁近黑底
- 上方:左「關閉」(44px 圓形叉叉)、右「下載」(膠囊,圖示加文字)
- 中間:圖片依寬度滿版顯示
- 下方:「小花 · 今天 09:16」
- 另外:點圖片外面、按 Esc 也要能關閉(設計稿無法表現)

### 4.4 畫面 B:電腦版

分成**左側聊天區**與**右側固定名單**(寬 260px)。

左側由上而下:

- **上方列**(高 64px):「匿名聊天室」+「你是 小明」;右側是文字按鈕「鉛筆圖示 更換代號」(電腦版有文字,不只是圖示)
- **進出提示**:同手機版,浮在訊息區上方
- **訊息列表**:兩側留 24px;泡泡最大寬 60%。**滑鼠移到自己的訊息上時**,泡泡左側出現兩顆 36px 的圓形圖示按鈕(編輯、刪除)
- **「有 N 則新訊息」按鈕**:同手機版
- **輸入區**:同手機版,下方多一行小字「Enter 送出 · Shift+Enter 換行 · 也可以直接貼上圖片」

右側名單:

- 標題列(高 64px,與左側上方列對齊):「● 線上 12 人」
- 清單,每行高 40px;自己那一行淡藍底、粗體、「(你)」
- **電腦版沒有**「N 人在線」膠囊,因為名單永遠看得到

#### 示意項目(不是網頁本身)

設計稿上有兩樣東西是示意瀏覽器的行為,實作時**不要畫在網頁裡**:

- **瀏覽器分頁列**上的「(3) 匿名聊天室」:實際做法是修改網頁的標題,見架構文件 7 之 B6
- **右下角的桌面通知**:由瀏覽器自己顯示,網頁只要發出通知

## 5. 響應式(手機與電腦的切換)

設計稿只有 390px 寬的手機與 1280px 寬的電腦兩個尺寸,中間尺寸需要實作時決定。建議:

- **約 768px 以下**:手機版(名單收進「N 人在線」,編輯與刪除靠點選訊息)
- **約 768px 以上**:電腦版(右側固定名單,編輯與刪除靠滑過)
- 平板這類可觸控的寬螢幕,**以「能不能滑過」而非螢幕寬度**決定要不要用滑過顯示的按鈕;不能滑過的一律用點選。

## 6. 實作時要注意的地方

1. **鍵盤彈出**:手機軟鍵盤出現時輸入區必須留在鍵盤上方。設計稿固定高 844px,實作要用能隨鍵盤變動的高度單位。
2. **訊息停在底部**:訊息少時貼底,多時可捲動,並維持「使用者不在底部就不要自動捲」的規則。
3. **無障礙**:
   - 只有圖示的按鈕都要有文字名稱(更換代號、加入圖片、送出、移除圖片、關閉、編輯、刪除、放大圖片)
   - 錯誤與狀態提示(代號被占用、連線橫幅、進出提示、頻率限制)要能被螢幕閱讀器讀到
   - 刪除確認視窗開啟時,焦點要鎖在視窗內,按 Esc 能關閉
4. **圖片的示意插圖**:設計稿中的山景是示意。實作時圖片來自使用者上傳,要限制最大顯示寬高,並在載入前先預留位置,避免版面跳動。
5. **長代號與長文字**:代號最長 12 字,但全形與半形寬度不同,版面要能容納;長文字、長網址要自動換行,不撐破泡泡。
6. **階段一的模擬器**要能呈現上面所有狀態(尤其是:被占用、載入更早、新訊息按鈕、斷線、頻率限制、空狀態),方便對照設計稿檢查。
